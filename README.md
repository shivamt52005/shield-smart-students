# Cyber Shield College

Build a complete, modern, responsive web application called:

“Social Engineering Defence and Cybersecurity Awareness Portal for College Students”

The purpose of the website is to educate college students about social engineering attacks and help them learn how to identify and avoid phishing, smishing, vishing, baiting, pretexting, impersonation, and other cyber threats.

Design

Create a professional cybersecurity-themed UI that looks like a real college cybersecurity awareness portal.

Modern, clean and responsive design

Dark cybersecurity theme with blue/purple accents

Professional dashboard cards and charts

Smooth animations and hover effects

Mobile, tablet and desktop responsive

Do NOT make it look like a hacker/terminal website

Use accessible typography and clear navigation

Pages

1. Landing/Home Page

Include:

Hero section

Project title

Short explanation of social engineering

“Start Awareness Training” button

“Test Your Knowledge” button

Statistics such as:

Students trained

Simulations completed

Threats identified

Why social engineering is dangerous

Types of social engineering attacks

Cybersecurity safety tips

Footer

2. Learn / Awareness Module

Create educational cards for:

Phishing

Smishing

Vishing

Pretexting

Baiting

Impersonation

Tailgating

Quid Pro Quo

Each topic should contain:

Definition

How the attack works

Warning signs

Example

How students can defend themselves

Add a progress indicator showing which modules the student has completed.

3. Social Engineering Simulator

Create a SAFE educational simulation.

Show realistic but fictional scenarios such as:

Scenario 1 — Fake College Email

“Your college account will be suspended today. Verify your account immediately.”

Give the student options:

This is legitimate

This is suspicious/phishing

After the answer, explain why the message is safe or suspicious.

Create multiple scenarios involving:

Fake college emails

Fake scholarship messages

Fake job/internship offers

Fake bank messages

Fake OTP requests

Fake social-media messages

Phone-call scenarios

DO NOT collect real passwords, OTPs, banking information or personal credentials.

4. Cybersecurity Quiz

Create a 15-question interactive quiz.

Features:

Multiple-choice questions

One question at a time

Progress indicator

Score calculation

Correct/incorrect feedback

Explanation for each answer

Final percentage

Awareness rating

Example ratings:

90–100% = Cyber Safety Expert
70–89% = Security Aware
50–69% = Needs Improvement
Below 50% = High Risk

5. Student Dashboard

Create a student dashboard containing:

Student name

Awareness score

Modules completed

Quiz scores

Simulation results

Progress percentage

Recent activity

Recommended training

Use charts/graphs to visualize progress.

6. Report Suspicious Activity

Create a page where students can submit a suspicious message for educational review.

Fields:

Message/email text

Type of suspected attack

Reason it looks suspicious

Optional screenshot upload

Show a confirmation after submission.

Do not request passwords, OTPs or other sensitive credentials.

7. Admin Dashboard

Create an admin dashboard showing:

Total registered students

Students who completed training

Average quiz score

Number of suspicious messages reported

Most common attack type

Student performance chart

Recent reports

Include tables for students and submitted reports.

8. Login and Registration

Create:

Student registration

Student login

Admin login

Logout

Basic authentication

Students should have their own dashboard.

Admins should have access to the admin dashboard.

Gamification

Add:

Points

Badges

Awareness levels

Progress bars

Leaderboard

Example badges:

Phishing Detective

Security Rookie

Cyber Guardian

Social Engineering Expert

Important

This is an educational cybersecurity project.

All simulations must be harmless and fictional.

Do not create real phishing pages, credential harvesting, password collection, OTP collection, malware, or attacks against real websites.

Use sample/mock data where backend functionality is not available.

Make the website feel like a complete final-year/college project rather than a simple landing page.

Also include realistic sample students, quiz results, reports and dashboard statistics so the UI looks populated when first opened.
